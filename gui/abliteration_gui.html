Abliteration walkthrough

What we are doing

A chat model's safety training makes it refuse harmful requests. Arditi et al. (2024) showed that "I am about to refuse" is a single direction in the model's internal activations. Abliteration finds that direction and removes it from the weights. This page replays a real run, layer by layer, so you can see how the direction is measured, tested and removed.

The residual stream

The model processes text through layers. After every layer, each token is a vector of numbers, the residual stream. Each layer reads from it and adds something back. We look at the vector of the last token of the prompt, which is the moment the model decides how to begin its answer.

How to read it

  • Early layers are low: the model is still processing words and has not yet "understood" whether the request is harmful.
  • The middle rises: the concept forms here. The good candidates usually live in this region.
  • Only the blue range () is tested in step 3, because very early layers carry no concept yet and very late layers already encode the output tokens.

Step 2 · Is it the same direction in every layer?

Each candidate direction is compared with every other one (cosine similarity, 1 = identical, 0 = unrelated). A large block of high similarity means the model carries one refusal direction through many layers. That is why removing a single direction from all layers works.

1 = same direction0 = unrelated−1 = opposite

Neighbouring layers

Similarity between layer L and L+1. Values near 1 mean the direction barely changes from one layer to the next.

Step 3 · Scan: remove each candidate and count refusals

Baseline first: the untouched model answers held-out harmful prompts and refuses of them. Then, for each layer's candidate direction, the direction is subtracted from the activations of every layer (a temporary hook, no weight change) and the model answers again. Step 4 · Choose a layer

Fewest refusals wins, but only if the answers stay coherent and in English. The rule used in this run: fewest refusals, then the lowest share of Chinese characters, then the earlier layer.

Step 5 · Apply: write it into the weights

The hook in step 3 was temporary. Now every matrix that writes into the residual stream is changed so it can no longer produce the direction r: the token embedding, every attention output projection (o_proj) and every MLP output projection (down_proj).

W′ = W − r rᵀ W

Projecting out the component along r. Anything the matrix writes is now orthogonal to the refusal direction. The check below multiplies r with every edited matrix: the result should be ~0 (bf16 rounding leaves ~1e-3).
