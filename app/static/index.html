run

Pick a GLM model, press Run, watch the refusal direction disappear.

Every prompt flows through the model's layers. Harmful requests push the residual stream along one direction; abliteration measures that direction, tests which layer's version removes refusals best, and projects it out of the weights. The guide below explains each step as it happens, with what to look for and what changes for GLM-5.x.

1 · Model Hugging Face repo or local folder · safetensors only, no remote code by default

2 · Run measure → scan → choose → apply → verify → validate → GGUF → Ollama

Refusal meter how strongly does each layer's refusal direction light up for this prompt?

The last-token activation is projected onto every layer's own direction and scaled between the harmless mean (0) and the harmful mean (1) measured in the run. Values near 1 mean "this looks like a request I would refuse" at that layer.
