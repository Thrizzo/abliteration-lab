Which GLM model?

Every GLM family is supported: the small Edge models run on this PC; GLM-4 needs CPU offload; the MoE giants (GLM-4.5/4.6, GLM-5.x) need a multi-GPU node and are listed so you can see what the method does there. Models are downloaded once from Hugging Face (safetensors only, no remote code).

Serving

Which run's abliterated model glm-serve gives the pentest copilot, and the kill switch for it. Promote a finished run after reading its validation; Rollback returns to the run before. Every change is kept in serving/history.json and the audit log.

Model server

Kill cuts the network, scales glm-serve to 0 and deletes its pod at once. Isolate cuts the network while the model keeps running; Release reopens it. Start brings a killed or stopped model back: a large model takes minutes to load. A response already streaming can outlive Isolate; Kill ends it.

Copilot

The abliterated model suggests, the policy gate (scope, rules of engagement) and a regular judge decide, and what passes is staged for execution. Nothing runs from here: the workflow's Execute node is disabled and no lab runner is configured.

Models the copilot is the n8n flow; it uses three

1Copilot model abliterated · proposes the command · served by glm-serve
2Judge regular model · approves or rejects the checked command against the RoE and the scope · the copilot's Ollama
3Search embedding model · turns your writeups into vectors for retrieval · writes no text, so it is not a choice here

Engagement

A command that names one is blocked; a command that could fetch it without naming it (wget -r, smbclient mget, curl [1-9]) waits for you. Write names, not hosts: HR$ is that share on every host; /backup/ is exactly the folder backup, backup also covers backup.zip.
