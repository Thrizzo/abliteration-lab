Which GLM model?

Every GLM family is supported: the small Edge models run on this PC; GLM-4 needs CPU offload; the MoE giants (GLM-4.5/4.6, GLM-5.x) need a multi-GPU node and are listed so you can see what the method does there. Models are downloaded once from Hugging Face (safetensors only, no remote code).

Abliterate

One click runs the whole method: find the refusal direction, test it layer by layer, remove it from the weights, validate, and put both models into Ollama. Each step below explains itself while it runs. Earlier runs of this model can be opened at the bottom.
